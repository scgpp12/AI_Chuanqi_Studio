# AI Chuanqi Studio

传奇题材 AI 短剧《集魂》的幕布平台存档。2026-11-17 起项目无限期停止，这里是停工时幕布平台里的全部内容。

## 里面有什么

| 路径 | 内容 |
|---|---|
| `幕布_集魂/素材/` | 幕布里的图片和声音，共 1385 个，按原来在本机 `ClaudeUsers` 下的目录摆放：`审美/新剧定妆`（人物、怪物定妆）、`审美/场景库`、`传奇知识/场景库`、`传奇知识/识别图`、`参考图库/传奇物品库`、`声音/集魂_试听_1115` 等 |
| `幕布_集魂/素材清单.json` | 每个素材的仓库路径、md5、大小、原路径、幕布里的 asset_id |
| `幕布_集魂/数据表/*.json` | 幕布数据库各表导出：人物和人物版本、场景、道具、分镜、台词、待你确认、回复记录等 |
| `mubu_集魂_1117.db` | 幕布 SQLite 数据库整份备份（11-17），能直接用幕布平台打开 |
| `幕布_集魂/未放进仓库_超大文件.json` | 超过 GitHub 单文件上限没放进来的文件：比奇城全城原尺寸地图 1 张（109 MB） |

## 不在这里的

- 视频：出片、成片、测试片都不在幕布里，所以不在这里。
- 剧本、人物卡、设定等文字资料在本机 `ClaudeUsers\传奇剧本\`、`传奇知识\`，这次没放。
- 幕布平台的代码在本机 `ClaudeUsers\幕布平台\`，天气预报项目还在用，这次没放。

## 怎么找一张图

1. 按目录翻 `幕布_集魂/素材/`；
2. 或者在 `素材清单.json` 里按名字或 md5 搜；
3. 人物用的是哪张图，查 `数据表/character_version.json` 的 face、front、side、back 几个 asset_id，再到素材清单里对应。
